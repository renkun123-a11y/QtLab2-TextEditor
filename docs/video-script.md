# 实验二演示视频录制脚本

给录制用的分镜脚本：按顺序做，每一步都写清楚“点哪里 / 输入什么 / 屏幕上应该出现什么”。
完整录一遍约 5～6 分钟；时间紧就只录带 ★ 的步骤（约 2 分钟）。

## 一、录制前准备

1. 启动程序：双击 `E:\Qt作业\lab2-text-editor\run.bat`（它会临时把 Qt 的 bin 目录加进
   PATH，直接双击 exe 可能提示缺 DLL）。
2. 窗口拖到屏幕中间，大小约 1000×700；关掉微信、QQ 等弹窗，任务栏收起来。
3. 建议 1080p、30fps 录屏（Win+G 或 OBS 的“窗口采集”都行）。
4. 鼠标移动放慢，每次点击后停 1 秒再操作下一步，方便后期剪。

## 二、演示时输入的文字（照这个打）

新建文档后输入下面 4 行（也可以直接从 `samples/demo_input.txt` 复制粘贴）：

```text
小牛文本编辑器演示
第一行：中文输入与换行测试
第二行：The quick brown fox jumps over the lazy dog.
第三行：hello world
```

> 输入法不方便时，先把 `samples/demo_input.txt` 用记事本打开，复制内容，
> 在编辑器里 Ctrl+V 粘贴即可，视频里看不出区别。

## 三、分镜脚本

| # | 操作（点哪里 / 按什么） | 屏幕上应该看到 | 口播提示 |
| --- | --- | --- | --- |
| 0 | 双击 `run.bat` | 主窗口出现，标题“新建文本文件 - 小牛文本编辑器” | 这是 Qt 实验二的简单文本编辑器 |
| 1 ★ | 鼠标依次指菜单栏、工具栏、左侧行号、底部状态栏 | 菜单 5 组、工具栏 3 组共 17 个按钮、状态栏 6 项 | 界面用 Designer 搭建，菜单和工具栏都由 QAction 生成 |
| 2 ★ | 按 `Ctrl+N`（或 文件 → 新建） | 空白文档，行号 1，状态栏 length: 0 | 先新建一个文档 |
| 3 ★ | 输入上面 4 行文字 | 行号随行数增加，length / lines / Ln / Col 实时变化，标题前出现 `*` | 行号、光标位置、字符数都是实时更新的 |
| 4 ★ | 按 `Ctrl+S` → 在“另存为”对话框的文件名里输入 `demo.txt` → 保存 | 标题变成 `demo.txt - 小牛文本编辑器`，`*` 消失，状态栏提示“已保存到 demo.txt” | 保存后标题的星号消失；不写扩展名也可以 |
| 5 ★ | 按 `Ctrl+O` → 输入 `E:\Qt作业\lab2-text-editor\samples\sample_utf8.txt` → 打开 | 中文正常显示，状态栏编码显示 `UTF-8` | 打开一个 UTF-8 文件 |
| 6 | 再按 `Ctrl+O` → 打开同目录的 `sample_gbk.txt` | 中文同样正常，状态栏编码变成 `GBK` | 没有 BOM 时先试 UTF-8，失败再按 GBK 解码；保存时按原编码写回 |
| 7 ★ | 用鼠标选中第 8 行（`hello again…`）→ `Ctrl+C` → `Ctrl+End` → 回车 → `Ctrl+V` | 文末多出一行，状态栏提示“粘贴剪贴板中的内容” | 剪切/复制只在有选区时可用，粘贴看剪贴板 |
| 8 | 点“编辑”菜单，展开后先不选，指一下灰色项 | 没有选区时“剪切”“复制”是灰的，“粘贴”可用 | 按钮使能跟着编辑状态走 |
| 9 ★ | 按 `Ctrl+Z` 撤销，再按 `Ctrl+Y` 重做 | 粘贴的内容消失又回来 | 撤销/重做走 QPlainTextEdit 自带的撤销栈 |
| 10 ★ | 按 `Ctrl+F` → 查找目标输入 `hello` → 点“查找下一个” 4 次 | 依次选中 3 处 hello，第 4 次状态栏提示“已到文档末尾，从开头继续查找” | 查找是循环的，到末尾会回到开头 |
| 11 | 把查找目标改成 `zzz` → 点“查找下一个” | 弹窗“未找到‘zzz’。”，点 OK 后点“取消”关闭对话框 | 找不到时给出明确提示 |
| 12 ★ | 按 `Ctrl+H` → 查找 `hello`、替换为 `HI` → 点“全部替换” | 弹窗“已替换 3 处。”，正文 3 处 hello 变成 HI | 连续替换不会每次弹“未找到” |
| 13 ★ | 按一次 `Ctrl+Z` | 3 处 HI 一次性全部变回 hello，标题 `*` 消失 | 全部替换用 beginEditBlock 合成了一次撤销 |
| 14 ★ | 格式 → 字体 → 选 `Consolas`、大小 `14` → OK | 编辑区字体变化 | 字体、字号都能改 |
| 15 | 选中一行 → 格式 → 字体颜色 → 选红色 → OK | 选中的文字变红 | 有选区作用于选区，没选区作用于之后输入的文字 |
| 16 | 选中一行 → 格式 → 字体背景色 → 选黄色 → OK | 选中的文字出现黄色底纹 | 同上 |
| 17 ★ | 格式 → 编辑器背景色 → 在 HTML 框里输入 `#fdf6e3` → OK | 整个编辑区变米黄色，行号区和当前行高亮自动适配 | 底色变深时文字颜色也会自动换 |
| 18 ★ | 按 `Ctrl+L` 关行号，再按一次打开 | 行号区消失 / 恢复 | 行号可以随时开关 |
| 19 | 按 `Ctrl+O` 打开 `samples\long_line.txt`（若弹出“保存修改”点“不保存”），再按 `Ctrl+Shift+W` 关/开自动换行 | 长行折行显示，但行号仍只占一个 | 折行只是显示效果，不影响行号 |
| 20 | 点“查看”→“工具栏”，再点一次 | 三条工具栏隐藏 / 恢复；状态栏还在实时更新 | 工具栏、状态栏都能整体隐藏 |
| 21 | 点“查看”→“状态栏”，再点一次 | 状态栏隐藏 / 恢复 | |
| 22 | 点“文件”→“自动保存”打勾 | 状态栏变成“自动保存: 开”；改一个字，等 60 秒后标题 `*` 消失 | 每 60 秒静默保存一次（录制时可口头说明、不真等），演示完把勾去掉 |
| 23 ★ | 再改一个字 → 点窗口右上角 × → 在“保存修改”里点“取消” | 弹窗“文档‘xxx’已被修改。是否保存修改？”，点取消后窗口不关、内容还在 | 未保存关闭会先询问，取消就不关 |
| 24 | 再点 × → 点“不保存” | 程序退出 | |
| 25 | 帮助 → 关于 | 显示程序名、图标、开发者、学号、邮箱、V1.0 build 202611 | 程序信息统一放在 appinfo.h |
| 26 | （可选）切到浏览器打开 GitHub 仓库 | 6 次提交记录 | 代码用 Git 管理，过程见 docs/dev-log.md |

## 四、异常场景（可选加录，约 1 分钟）

三个异常都可以用命令行带文件参数启动，不用手动找路径：

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 打开不存在的文件 | 命令行运行 `run.bat D:\nope\missing_file.txt` | 弹窗“文件不存在：D:\nope\missing_file.txt”，程序继续运行 |
| 打开二进制文件 | 命令行运行 `run.bat E:\Qt作业\lab2-text-editor\samples\fake_binary.dat` | 弹窗“‘fake_binary.dat’看起来是二进制文件，不是文本文件，已取消打开。” |
| 保存到只读文件 | 先执行 `attrib +R E:\Qt作业\lab2-text-editor\samples\readonly.txt`，打开该文件、输入一行、Ctrl+S | 弹窗“无法保存文件：…”，提示“文件是只读的，没有写入权限。”，标题仍有 `*`；录完执行 `attrib -R` 还原 |

## 五、常见问题

- **对话框是英文**：字体、颜色、消息框用的是 Qt 自带对话框，没有加载中文翻译，
  这是正常的；自己写的“保存修改”“查找/替换”“关于”都是中文。
- **双击 exe 报缺 Qt6Widgets.dll**：用 `run.bat` 启动，或把 `E:\Qt\6.7.2\mingw_64\bin`
  加进 PATH。
- **找不到 samples 目录**：位于 `E:\Qt作业\lab2-text-editor\samples\`。
- **中文路径**：本项目就放在中文目录下，编译/运行没有问题；如果换机器编译失败，
  按 README 的注意事项把构建目录放到英文路径。
